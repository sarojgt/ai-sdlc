# ai-sdlc

AI SDLC repository scaffold for configuration, context, design, schema, template, and initiative artifacts.

## Repository structure

- `config/` contains lifecycle, gate, role, skill, context, agent provider, HLD loop policy, and security baseline definitions.
- `context/` contains consistent cross-initiative context and guardrail directories.
- `design/` contains architecture and process design documentation.
- `schemas/` contains shared schema definitions.
- `templates/` contains reusable agent and initiative templates.
- `initiatives/` contains initiative-specific workspaces.
