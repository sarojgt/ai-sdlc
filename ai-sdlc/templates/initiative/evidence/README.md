# Evidence

Generated context snapshots, HLD impact assessments, agent requests and
responses, validation output, source hashes, and deployment evidence belong
here. Evidence is generated by the workflow and should not normally be
authored manually.

`hld-assessment.yaml` is the machine-readable preflight classification used to
select the small, medium, or large HLD profile before full generation. It is
not an architecture approval. If a run fails after producing `hld/hld.md`, a
resume run can reuse the existing HLD, create or repair this assessment, and
continue with AI review.
