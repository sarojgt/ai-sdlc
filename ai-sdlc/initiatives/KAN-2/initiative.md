# Initiative: Add card search endpoint filtered by customer name

## Summary

- Initiative ID: `KAN-2`
- Owner: `team.cards`
- Source work item: `KAN-2`
- Status: intake

## Business outcome

Allow support and internal users to search cards by customer name so they can
quickly locate related card records without manually checking multiple systems.

## Scope

### In scope

- Read-only card search endpoint filtered by customer name.
- Pagination, standard validation/error handling, authorization, logging, and API documentation.

### Out of scope

- Card creation or update.
- Customer profile changes.
- New search UI.
