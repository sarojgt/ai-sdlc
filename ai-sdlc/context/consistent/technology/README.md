# Technology Context

Technology choices are governed by the GitHub Tech Radar. The radar ring is
important context, not an automatic approval for every initiative:

- **Adopt** — preferred for new work when the initiative fits the capability.
- **Trial** — use for bounded evaluation with an owner and success criteria.
- **Assess** — investigate suitability before selecting it for a material
  design.
- **Hold** — avoid for new work unless an exception or existing-use case is
  explicitly justified.

The repository snapshot is used by AI for repeatable HLD generation. The
GitHub Tech Radar remains the upstream source of truth.
