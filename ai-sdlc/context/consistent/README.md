# Consistent Context

Consistent context is shared knowledge that is reused across initiatives and
changes relatively slowly.

Use Markdown for human-owned content. Each document should identify its owner,
review cadence, scope, and authoritative status near the beginning of the file.

## Categories

- `business/` — industry, regional, product, domain, glossary, and business
  definitions.
- `architecture/` — architecture principles, technology standards, API
  principles, platform patterns, and reference architectures.
- `platform/` — reusable shared capabilities, eventing, delivery, and
  operational patterns.
- `technology/` — Tech Radar rings and technology-selection guidance.
- `product/` — Banking.Live, PayCredit, Program Management, Disputes, and
  other reusable capability context.

Imported documents are curated snapshots, not blind copies. Follow the source
link in each document and confirm current status before a material decision.
