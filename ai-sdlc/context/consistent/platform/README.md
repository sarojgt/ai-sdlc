# Platform Context

This directory contains reusable platform capabilities and engineering
patterns. The files are curated Markdown snapshots from Confluence. Each file
records its upstream source and retrieval date.

Confluence remains the upstream source of truth. Changes to these snapshots
must be reviewed through GitHub before they become inputs to a governed HLD.

The Lume context distinguishes the strategic target model from tactical
transitional deployments. AI must always state which model it is using and
must give tactical exceptions an owner, risk assessment, and convergence path.
