# Product and Capability Context

This directory contains reusable product and platform capability context for
Banking.Live, PayCredit, Program Management, Disputes, and related portals.

Product context describes responsibilities and boundaries. It does not replace
initiative-specific requirements or current repository/runtime evidence.

The `services/` subdirectory contains the concise Banking.Live service and
repository catalogue. Use those pages to identify likely repositories, then
confirm the current implementation and runtime evidence before design approval.
